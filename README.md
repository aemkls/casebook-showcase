# Casebook — showcase

Casebook — веб-приложение для изучения судебной практики Казахстана: опишите ситуацию своими словами и посмотрите, как суды решали похожие дела, чем они заканчивались и какие обстоятельства упоминались в мотивировке, а затем откройте полный текст акта.

> Это **демонстрационная версия** проекта: код и по три примера из каждого раздела. Полная коллекция документов и рабочие данные в репозиторий не входят.

## Что умеет приложение

- Три раздела: **административные**, **уголовные** и **гражданские** дела с единым интерфейсом.
- Поиск по описанию ситуации, реестр с фильтрами по теме и исходу, поиск по номеру дела.
- Таблица обстоятельств: какие формулировки встречаются в мотивировках и как они распределяются по исходам.
- Полный текст акта; в уголовных и гражданских делах имена заменены на ФИО-1, ФИО-2 и т. д.
- Работает целиком в браузере: запрос пользователя не уходит на сервер и не обрабатывается языковой моделью.

## Как это устроено

```text
сырые тексты ──> anonymize_*.py ──> build_*.py ──> offline-payload.b64 + source-bundles/*.json.gz
                 (ФИО-N, ИИН, адреса)  (тема, исход,      │
                                        карточки, индекс)  ▼
                                                  frontend/ ──> scripts/build.py ──> static/practice.html
```

- `scripts/anonymize_criminal.py`, `scripts/anonymize_civil.py` — обезличивание: правила, модель Natasha и словарь pymorphy3.
- `scripts/build_criminal.py`, `scripts/build_civil.py` — разметка (категория, исход, наказание, обстоятельства) и сборка индекса.
- `scripts/validate_data.py` — проверка, что в опубликованных текстах не осталось «Фамилия И.О.», полных ФИО и ИИН.
- `frontend/` — интерфейс на HTML, CSS и JavaScript без фреймворков; индекс и поиск работают в Web Worker.
- `scripts/build.py` — собирает единую страницу `static/practice.html`.

Подробнее: [docs/architecture.md](docs/architecture.md).

## Что в репозитории

| Путь | Содержимое |
| --- | --- |
| `static/data/criminal/`, `static/data/civil/` | по три обезличенных примера в рабочем формате |
| `examples/admin/` | три обезличенных примера административных решений в виде текста |
| `scripts/` | обезличивание, сборка, проверки |
| `frontend/`, `static/practice.html` | интерфейс и собранная страница |

Раздел административных дел в демонстрации не работает: данные для него намеренно не включены.

## Запуск демонстрации

```bash
python3 -m http.server 8000 --directory static
```

Откройте `http://localhost:8000/practice.html#criminal/question` или `#civil/question`.

Для пересборки данных из собственных текстов: `pip install -r requirements-data.txt`, затем `anonymize_*.py` и `build_*.py` (см. `--help`).

## Ограничения

Разметка и обезличивание автоматические и могут ошибаться. Приложение — исследовательский инструмент: оно не даёт юридических консультаций и не оценивает вероятность исхода дела.
